## 0. 架构与配方

```
x (161)
  └─ ResidualTrunk（depth 2，无 norm，共享）
        block0      : Linear(161→48) + ReLU
        block1      : h = h + ReLU(Linear(96→48)(ReLU(Linear(48→96)(h))))
  └─ h (48)
        ├─ actor   : PlainHead [Linear(48→48)+ReLU] → Linear(48→138)
        ├─ critic  : Linear(48→1)
        └─ outcome : Linear(48→1) → tanh          (--vf-outcome)
```

- 总参数 **26,348**（body 17,136 + actor 9,114 + critic 49 + 胜负头 49）；上一臂 (32,96,32)
  是 17,132。
- PPO：batch **2048**（`--num-envs 16` × `--num-steps 128`）、`--num-minibatches 8`
  （minibatch 仍 256）、`--update-epochs 2` → 每 update 16 个 minibatch 梯度步（与旧配方
  4×4=16 相同，只是数据切分不同）；总 **976 updates** = 1,998,848 步。

## 3. 读法

1. **全平**：对上一臂 −3.04、对 `head32ln5m` −3.77、对 `res421_h64_2m` −8.26，CI 全含 0。
   加宽流到 48、mid 保持 96、再把 batch 翻倍/epochs 减半，都没有产生可测的强度变化。
2. **训练内指标与 h2h 再次脱钩**：EV 0.6747（家族最高）、末行 outcome acc 0.9339、训练内
   eval win 0.90，但 h2h 不动；和上一轮「EV 相同、h2h 差 17」是同一现象的两侧。
3. **分辨率更差**：本 run 的 seed 间方差大（vs `t17long` between-seed sd 17.9、per-seed
   +20.0 / +0.4 / +36.2），所以这条 null 比前几个臂更钝；不能把「对 t17long +18.9」当成
   家族内那两条 +24.7 的同类读数（那条 CI 排 0，这条没有）。
4. **k=1**：未复现。
