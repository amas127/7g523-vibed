## 0. 架构

```
x (161)
  └─ ResidualTrunk（depth 2，无 norm，共享）
        block0      : Linear(161→64) + ReLU
        block1      : h = h + ReLU(Linear(16→64)(ReLU(Linear(64→16)(h))))
  └─ h (64)
        ├─ actor   : PlainHead [Linear(64→64)+ReLU] → Linear(64→138)
        ├─ critic  : Linear(64→1)
        └─ outcome : Linear(64→1) → tanh          (--vf-outcome)
```

- 总参数 **25,756**（body 12,496 + actor 13,130 + critic 65 + 胜负头 65）；块内 64→16→64，
  每个残差块只有 2,128 参数（h48 臂的 48→96→48 是 9,360）。
- 配置等价于 `--arch bres221 --hidden-size 64 --res-expansion 0.25`。

## 3. 读法

1. **压缩型瓶颈不是正杠杆**：对 h48 臂（同配方、只换块）−12.76、对族内最佳 h32 臂 −7.96，
   CI 都含 0 但点估计为负；对固定外部锚点 `head32ln5m`/`res421` 显著更差（−21.8 / −16.4，
   3/3 seed 负）。
2. **空间很宽但没帮助**：块内只有 16 维，参数降到 25.8k（h48 是 26.3k，h32 是 17.1k），
   但参数不是这条配方下的瓶颈——h32 臂用 17k 参数就能打平顶簇。
3. **old-recipe 优势仍在**：对 `t17long` +19.72（3/3 正），家族内所有臂都保留这一条。
4. **训练读数继续与强度脱钩**：末行 outcome_acc 0.9698、训练内 eval diff 59.9 都是家族里
   好看的一档，h2h 却低于 h32 臂。
5. **k=1**：未复现。
