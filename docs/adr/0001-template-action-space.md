# 动作空间：牌型模板目录 + 确定性实体化

> **扩展说明（[ADR-0004](./0004-suit-head.md)，2026-09-25）**：本 ADR 的模板目录与固定
> `action_mask` 决策仍现行；“暂不暴露花色级别的策略”已落地为 `MultiDiscrete([134, 4])` 的顶牌花色头，
> 且 `resolve()` 只对顶牌缺省取最强花色，其余牌固定取最弱花色（见 ADR-0004 §语义）。

规则引擎出牌是“实体牌组合”，但 RL 动作空间若枚举实体组合会因顺子的花色排列（长顺 `4^L`）爆炸；若每步动态枚举合法牌，则同一动作编号在不同局面含义不同，策略无法泛化。

因此决定：动作空间为**全牌局固定的抽象点数模板目录**（含 `PASS`），`resolve()` 从手牌确定性挑选实体牌（优先强花色）。这样 `action_mask` 长度固定、语义稳定，`ppo_multidiscrete_mask.py` 可直接复用；代价是暂不暴露花色级别的策略，保留后续扩展为 `(模板, top_suit)` 的路径。

## 考虑过的替代

- 实体牌组合目录：动作数爆炸。
- 每步动态合法列表：编号语义漂移，无法泛化。
- 54 维 `MultiBinary`：联合空间 `2^54`，掩码与探索均不可行。

## 后果

目录规模随规则固定（当前 134），测试将断言其大小以防静默漂移；花色只作同点数 tie-break，保花色策略暂不可学。
